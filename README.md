# EOS Trade Vision

## Sobre o Projeto

Sistema de visualização e análise de trading.

## Tecnologias

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Como Rodar Localmente

Requisito: Node.js & npm instalados - [instalar com nvm](https://github.com/nvm-sh/nvm#installing-and-updating)

```sh
# Clone o repositório
git clone <URL_DO_GIT>

# Entre no diretório do projeto
cd eos-trade-vision

# Instale as dependências
npm i

# Inicie o servidor de desenvolvimento
npm run dev
```

## Deploy

Execute `npm run build` para gerar a versão de produção.
